# Relax Space Residential Complex

## Project Overview

- This project aims to build the backend of a hypothetical residential complex named Relax Space Residential Complex.
- The backend has been implemented using FastAPI. MySQL has been used to maintain a database.
- In this project, real world backend technicalities like cookies, authentication, password hashing and database integration have been implemented.
